Network Details

Network Name: CHEESE Blockchain
Chain ID: 20250 (0x4F2A)
Currency: NCH (NCheese)
RPC URL: https://cheeseblockchain.com/api/rpc
Explorer: https://cheeseblockchain.com/explorer

📋 Manual Setup Instructions

If the automatic setup doesn't work, you can add the network manually:

  1. Open your Web3 wallet (MetaMask, Binance Wallet, etc.)
  2. Go to Settings → Networks → Add Network
  3. Enter the network details shown above
  4. Save and switch to the CHEESE Blockchain network
